MiniPC Backup

Private Datensicherung vom eigenen Mini-PC in das eigene Google Drive.

MiniPC Backup ist eine persönliche Einrichtung von Philipp, erreichbar über das GitHub-Konto C0d3Seeker. Sie ist ausschließlich für das eigene Google-Konto bestimmt. Es gibt keine Registrierung und kein Angebot für andere Nutzer.

Datenschutzhinweise lesen

So ist es vorgesehen

restic verschlüsselt ausgewählte lokale Dateien vor dem Upload. rclone überträgt die verschlüsselten Sicherungsdaten in Google Drive und lädt sie für Prüfungen oder Wiederherstellungen herunter.

Die Google-Anmeldung erlaubt den Zugriff auf die von dieser Anwendung erstellten beziehungsweise ausdrücklich für sie freigegebenen Drive-Dateien. Die Einrichtung soll nur ihre eigenen Sicherungsdateien verwalten.

Die Einrichtung wird derzeit vorbereitet. Diese Informationsseite bestätigt weder einen erfolgreichen Sicherungslauf noch eine geprüfte Wiederherstellung.
